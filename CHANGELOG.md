# Changelog

## 1.0.0 (first public release)

The first release. SwiftCut trims the start and end of videos, accurate to the frame.

- **Trimming:** draggable handles, typed times, frame nudges, set start/end at the playhead,
  undo/redo, and suggested trim points that skip a recording's frozen start and end (T).
- **Timeline:** filmstrip with hover preview, zoom (Ctrl + wheel) with an overview bar, and
  frame-exact stepping.
- **Saving:** keep the original format or choose MP4 / MOV / MKV / WebM with H.264, H.265 or
  VP9. NVIDIA GPU encoding, size limits (two-pass), live size estimate, metadata removal,
  per-track audio, and safe overwrite of the original.
- **Sharing:** GIF and animated WebP export, plus PNG frame snapshots.
- **Comfort:** remappable shortcuts (classic and WSAD), Basic/Advanced modes, preview volume and
  output device, drag-and-drop, single window, and an optional Explorer right-click entry.
- **Privacy:** no network connections, no telemetry.
- **Bundles** FFmpeg 9.0.2 and Qt 6.12.
